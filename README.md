# Movie Recommendation System 🎬

## Project Overview
The Movie Recommendation System is a machine learning project that recommends movies based on user preferences, movie genres, and ratings.

## Objectives
- Recommend movies based on genres.
- Analyze user movie ratings.
- Implement Content-Based Filtering.
- Implement Collaborative Filtering.
- Combine both methods using Hybrid Recommendation.

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- MovieLens Dataset

## Recommendation Techniques
1. Content-Based Filtering
2. Collaborative Filtering
3. Hybrid Recommendation

## Dataset
MovieLens Latest Small Dataset.

## How to Run
1. Open the notebook in Google Colab.
2. Run the code.
3. Select a recommendation method.
4. Enter a movie name or user ID.
5. View recommended movies.

## Project Type
Machine Learning Internship Project.
